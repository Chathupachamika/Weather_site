# 🌦️ **Weather Site** 🌦️

A responsive weather application that displays real-time weather information, temperature, and forecasts using weather API integration. Features a clean interface with dynamic updates and intuitive search functionality.

## 📝 **Project Overview**

The **Weather Site** project is a modern weather application that allows users to access real-time weather data, including current conditions, hourly forecasts, and a 7-day outlook. With its clean and responsive design, the application offers smooth navigation and dynamic updates, making it easy for users to check the weather anywhere, anytime.

## 🚀 **Features**

- **Real-time weather data**: Get current temperature, humidity, wind speed, and more.
- **Search functionality**: Search for weather information by city.
- **Hourly forecast**: View weather data for the next several hours.
- **7-day forecast**: Detailed forecast for the next week.
- **Responsive design**: Works seamlessly on both mobile and desktop devices.
- **Weather icons**: Intuitive icons to represent different weather conditions.
